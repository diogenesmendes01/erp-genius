# Inbox350 — imagens de comparação

36 PNGs originais, organizados em18pares APP/PROTO: resposta pendente, tarefa pendente e aprovado, em1440×900,1024×768 e390×844, claro e escuro. Representante: app-resposta-pendente-desktop-claro.png.

Proveniência:18APP do formalV4;10PROTO pendentes do PROTO-onlyV2 (excluídas as duas respostas/tablet anteriores);6PROTO aprovadas por UI original em lote próprio;2PROTO resposta/tablet do reenquadramentoV2. Cada PNG mantém seus bytes originais, sem reencode, colagem ou recorte. O manifesto contém o índice nominal, lote, bytes, SHA256 e dimensões.

Os dois lotes iniciais terminaram globalmente negativos após suas candidatas individuais; os negativos, marcadores e manifestos brutos permanecem privados e preservados. Este corpus não reclassifica esses executores. As comparações finais precisam do parecer de QA e da autorização de publicação do integrador.

- Corpus composto por quatro lotes; negativos globais preservados, sem reclassificação de execução
- PROTO é referência visual estática; não comprova autoscroll, posição da thread, foco ou comportamento após seleção
- Resposta PROTO é pacote original com três ações; APP350 exibe cartões individuais. Edição/pacote D2 pertencem a355/356
- Comparação estrutural e visual; não afirma identidade de pixels nem cenas idênticas
- Nenhuma aprovação/rejeição/envio de negócio foi acionada no APP para obter estas imagens

O ZIP contém somente36imagens, este README e manifesto.json. Nenhuma credencial, caminho absoluto, cabeçalho, log bruto, ID de fixture ou executor privado está incluído.
